## 🏛️ Mission 3: The Majapahit Empire - Binary Tree
**File:** `BinaryTreeExercise.java`

**Objective:**
Help **Mpu Prapanca** organize the historical figures of the Majapahit Empire! You must implement a **Binary Search Tree (BST)** to index the key figures named in the chronicles.

**Core Concepts:**
The program includes a built-in guide on **Tree Fundamentals** (Root, Node, Leaf, etc.) printed at the start.

**Your Tasks:**
1.  **The Royal Node**: Complete the `Node` class constructor.
2.  **Coronation (Insert)**: Implement the BST logic to add figures recursively.
    *   *Left*: Name alphabetically **smaller** than Root.
    *   *Right*: Name alphabetically **larger** than Root.
3.  **Appraisal (Traversal)**:
    *   **InOrder**: Alphabetical sorting (A-Z).
    *   **PreOrder**: Hierarchical structure.
    *   **PostOrder**: Historical archives (Bottom-up).

**Visual Guide (Majapahit Hierarchy):**
```

        /           \
   Jayanegara    Tribhuwana
   /        \
Gajah Mada  Kertanegara

   Hayam Wuruk
```
